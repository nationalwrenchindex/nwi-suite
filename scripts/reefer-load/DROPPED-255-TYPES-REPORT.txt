REEFER PARTS LOAD - THE 255 PARTS HELD FOR WANT OF A PART TYPE. Report only; no SQL.
Written 2026-11-04 from scripts/reefer-load/REPORT.txt (the held list), the source files in
data/parts-sources/, and a read-only SELECT of the live store (2700 parts, 141 part types).

Every one of the 255 comes from ONE source: reefer-parts-master (Reefer-Parts-Master.xlsx,
sheet "All Parts"; row numbers below count the header as row 1). No other source file carries
any of these numbers except parts-needs-review.csv, which holds the same rows. Master gives NO
description for any of them - only a part_name, which is often its catalog SECTION HEADING
("Evaporator coil - evaporator fan", "Sensor/switch"), not the part.

HEADINGS. The counter (src/lib/parts/counter.ts, categoryOf) has 8 named headings - Engine,
Fuel, Maintenance & Wear, Belts & Drives, Refrigeration, Electrical & Controls, Air Flow &
Structure, Electric Standby - plus Other for anything its rules do not match. For each type
below, "belongs" is the heading the part belongs under; "counter today" is where categoryOf
would actually file that name as the code stands. They differ for 8 of the 12 proposed
types: any name containing "oil" lands in Maintenance & Wear (that rule runs first, and
"coil" contains "oil"), and tank / sight glass / piston / rocker / camshaft match no rule
and land in Other. That is a counter change in src/, not a naming choice - not made here.

SUMMARY
  219 need one of 12 NEW types (section 1)
    2 are MAPPING BUGS - an existing type covers them (section 2)
   25 are "Sensor/switch" - no type proposed; each is one of the existing sensor/switch types (section 3)
    9 are single oddities that need your call (section 4)
  ---
  255

NAMING. The store uses two styles side by side (section 5): "Kind - qualifier" for filters,
sensors, solenoids and switches (Filter - air, Sensor - temperature), and a plain noun phrase
for everything else (Receiver tank, Fan motor, Compressor oil pump, Expansion valve (TXV)
retrofit kit). None of the 12 is a filter, sensor, solenoid or switch, so all 12 use the
plain style, each named after its nearest existing neighbour.
